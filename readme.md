The core idea is to develop a framework to enhance LLMs' capability in translating low-resource languages (like Luxembourgish) leveraging reasoning skills.  



The pipeline includes leveraging reinforcement learning - with considered algorithm Group Relative Policy Optimization (GRPO) - to allow the model to reason through complex grammar rules: as we talk about low-resource languages, by enhancing the model's reasoning skills, we aim at compensating the lack of visibility during pretraining.
